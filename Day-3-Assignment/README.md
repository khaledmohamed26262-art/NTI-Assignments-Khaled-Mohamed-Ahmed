# NTI Assignment 3

**Name:** Khaled Mohamed Ahmed

This assignment contains solutions for 38 questions.

The related questions were grouped into 8 programs to keep the files organized and make the programs easier to run and test. No question was removed. The original question numbers are written as comments inside each `main.c` file.

## Programs

### 1. program-01-pointers-and-swap
Contains pointer operations, passing variables by address, and swapping values.

### 2. program-02-array-operations
Contains the related array problems.

### 3. program-03-search-sort-string
Contains searching, sorting, and string problems.

### 4. program-04-number-operations
Contains integer, digit, and number calculation problems.

### 5. program-05-bitwise-operations
Contains set bit, clear bit, toggle bit, read bit, shifting, and other bitwise operations.

### 6. program-06-state-memory-frame
Contains state, memory, and frame processing problems.

### 7. program-07-toggle-led-embedded
ATmega32 embedded program that toggles an LED using DIO.
